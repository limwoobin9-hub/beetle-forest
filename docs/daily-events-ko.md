# 매일 사건과 사육 관리

사건은 선택지 시험 대신 직접 행동하는 미션이다. 한국 날짜마다 각 세계에 새 미션 하나가 나온다. 좋은 사건과 문제 해결 사건을 각각 50%로 뽑고, 최근 일주일에 나온 이야기는 피한다. 구체적인 사건 제목 200개(좋은 사건 100개, 문제 사건 100개)를 31종과 조합한다. 종 조합을 별개의 이야기로 세지 않는다.

미션에는 실제 시간 대기 1~3회와 각 단계의 작업 버튼이 있다. 총 대기는 2~6시간이며, 시작 후 24시간 안에 마지막 대기를 끝내면 보상을 받을 수 있다. 예를 들어 응애 대량 발생은 톱밥 전부 꺼내 살균하기(3시간) → 살균한 톱밥 펼쳐 식히기(1시간) → 톱밥 다시 깔고 보상 받기이다. 빗물 문제는 빗물 닦기(1시간) → 톱밥 말리기(2시간) → 톱밥 식히기(1시간) → 사육장 정리하기이다. 다음 단계는 플레이어가 다시 들어와 버튼을 눌러야 시작된다. 가상 세계의 다음 날 버튼으로 대기를 건너뛰지 못한다.

기한은 자정이 아니라 시작 시각부터 24시간이다. 남은 대기까지 기한 안에 마칠 수 없는 후속 작업은 시작하지 못한다. 미시작 미션은 다음 날짜에 종료하고, 진행 중인 이전 미션과 이미 얻은 보상은 접힌 목록에 보관한다. 마지막 대기가 기한 안에 끝났다면 며칠 뒤 방문해도 보상을 받을 수 있다. 오래 접속하지 않았어도 현재 날짜 미션 하나만 생성한다.

실제 한국 시각의 밤에는 밤 손님 미션이 나온다. 현실의 숲에서는 설정된 지역의 기존 실시간 날씨 기능과 연결하여 비·뇌우 때 빗물 관련 미션, 더운 낮에 차광막 미션의 확률을 높인다. 밤 손님은 밤에만, 빗물 문제는 실제 비·뇌우에만, 폭염 문제는 낮 기온 28도 이상에만 생성한다. 날씨를 받지 못하면 시각과 보유 상태를 사용한다. 당일 이미 정해진 미션은 날씨·지역 변경이나 재접속으로 바뀌지 않는다.

사건으로 성충이나 유충이 죽거나, 기존 매트·균사·젤리·잎사귀를 잃지 않는다. 청소 미션을 끝내면 시작할 때 보유하던 성충의 청결이 100이 된다. 의뢰 재료는 의뢰인이 제공하며, 선물 정리·이웃 부탁 일부 미션은 실제 용품도 보상한다. 균사 청소는 균사병을 사용하는 번식통이 있을 때, 사육통 문제는 보유 곤충이 있을 때, 매트 정리는 매트 재고가 있을 때 나온다.

보상은 잎사귀와 경험치 20이며 한 번만 지급한다. 방문·구조·야간 손님 미션은 희귀 특성 개체를 사육실로 바로 데려온다. 사육 공간이 부족하면 돈을 먼저 지급하고 손님은 공간이 생길 때까지 보관한다. 손님의 크기·성별·특성은 저장된 값으로 고정되어 재접속으로 바뀌지 않는다. 손님은 채집 횟수를 늘리지 않는다. 국내 창문 손님은 국내 종에서 뽑는다.

사건 버튼은 사육 일수·설정 옆에 있고 상단 탭은 기존 8개이다. 화면은 오늘 미션 한 장에 발생한 문제, 보상, 현재 작업, 남은 시간, 다음 행동 버튼을 표시한다. 기존 사건 저장은 시작한 작업의 대기 시각, 완료 보상, 돈을 받은 뒤 아직 데려오지 않은 손님을 보존한다. 기존 미시작 선택지 사건은 새 미션 방식으로 대체한다.

하루 사육 지원금은 기본 15 + 살아 있는 사육 성충당 2 + 번식통 후손당 1 + 건강 75·포만감 40 이상인 성충당 1이며 하루 최대 80 잎사귀다. 하루 진행 후 돌봄 상태를 사용하며, 우화하는 날은 번식통 후손으로 한 번 계산하고 다음 날부터 성충으로 계산한다. 사망 개체·표본·경매 보관 개체는 제외한다.

여러 마리 방생은 보유 개체 목록의 선택 모드에서 개별 선택 또는 표시된 개체 선택을 사용한다. 필터 밖 선택 개체 수도 표시하고 최종 확인 목록에 모두 포함한다. 취소는 선택을 유지하고, 세계나 다른 메뉴로 이동하면 선택 모드를 종료한다. 투곤 참가 개체는 선택하지 못하며, 잘못된 개체가 하나라도 포함된 방생은 전부 취소된다. 도감 기록·후손의 부모 스냅샷·라인 기록은 보존한다.
