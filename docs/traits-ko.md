# 희귀 특성과 유전

모든 종의 수컷과 암컷에게 같은 확률로 특성이 부여된다. 턱 특성은 암컷에서 큰턱으로 표현하지 않고 ‘혈통’으로 표시한다. 특성은 크기 잠재력이나 투곤 능력을 올리지 않으며, 크기·성별과 독립적으로 결정한다.

## 특성별 게임 설정

2026-10-04에 사육자·판매자의 직접 기록을 검색해 특성 종류와 희귀도 기준을 정했다. 2026-10-06에는 장기 플레이에서 특성을 너무 드물게 만나는 문제를 해결하기 위해 등장률을 최소 5배 올리고, 모든 종의 특성 등장 합계를 최소 6%로 맞췄다. 희귀도 등급과 경매 가산 배율은 기존 기준을 유지한다. 아래 수치는 **실제 자연 발생률 통계가 아니라 자료의 희소성 설명을 참고한 게임 설정**이다. 자연 상태와 선별 누대 사육을 같은 모집단으로 보지 않았으며, 지역·아종·크기별 사례의 비율을 국내 전체 발생률로 환산하지 않았다. 컬러아이 사이의 세부 순위도 게임 난이도를 위한 설정이다.

자연 발현 확률은 해당 종의 개체 1마리 기준이다. ‘특성이 이미 뜬 뒤 그중 이 특성이 나올 확률’이 아니다. 평가 배율은 같은 종·성별·크기·상태의 기본형에 특성 하나가 붙었을 때의 배율이며 실제 낙찰가를 보장하지 않는다.

왕사의 극태는 사용자의 선호에 따라 제외했다. 곡치는 턱의 두께를 늘리지 않고 곡률을 표현한다. 홍다리·다우리아·두점박이의 특성 이름은 외형에서 착안한 **게임 변이**다. 실제로 고정되었거나 희귀하게 유전되는 사육 혈통이라는 주장은 하지 않는다. 실제 곤충의 형태는 유전뿐 아니라 크기·성장 환경 등에도 영향을 받는다.

특성 자연 발현 합계는 왕사 6%, 넓사 14%, 장수 9.75%, 톱 7.5%, 홍다리·다우리아·두점박이·애·사슴 각각 6%다. 나머지는 기본형이며 자연 발현에서는 한 특성만 뽑는다. 다른 턱 형태나 다른 눈 색은 동시에 보유할 수 없다. 유전으로 다른 분류의 특성을 최대 두 개까지 보유할 수 있다.

한쪽 부모 보유 30%, 같은 특성의 암수 75%라는 **게임 유전 확률**을 적용한다. 한쪽 부모 확률은 2026-10-05에 15%에서 30%로 조정했다. 자손마다 독립적으로 적용하며 실제 멘델 유전 확률을 뜻하지 않는다. 번식 시 각 알의 성별·크기 잠재력을 먼저 결정하고 특성을 확정해 저장한다. 부모의 특성을 분류별로 추첨하며, 부모가 모두 보유하지 않은 분류에서만 위 특성별 자연 발현 확률로 새 특성을 추첨한다. 제외한 분류의 확률을 남은 특성에 재분배하지 않는다. 실패한 부모 특성을 자연 발현으로 다시 추첨하지 않으므로 화면의 30%·75%는 정확하다. 같은 분류의 다른 특성을 가진 부모는 각 특성 30%, 기본형 40%다. 우화·새로고침·시간 경과로 다시 추첨하지 않는다.

## 경매 반영

특성별 평가 배율은 `1.5 + 0.9 × log2(0.02 / 기존 희귀도 기준 확률)`을 소수 둘째 자리로 반올림한다. 희귀도가 높을수록 평가액과 입찰자 수요가 높아지되 발생률의 단순 역수로 경제가 폭증하지 않게 했다. 두 특성의 배율은 곱하지 않고 `1 + 각 특성의 (배율 - 1) 합계`를 적용한다.

성충·표본은 보유한 특성을 평가한다. 유충 묶음은 `1 + 각 부모 특성의 (배율 - 1) × 해당 특성 유전 확률 합계`를 적용한다. 같은 특성의 부모 둘을 중복 계산하지 않으며, 75%의 유전 기대를 사용한다. 미공개 자손의 특성·성별·크기 잠재력은 가격에 사용하지 않는다. 종 자체의 희귀도와 암수별 크기 비교는 별도로 유지한다. 출품 창과 출품 기록에 해당 특성의 희귀도·평가 기준을 표시한다.

이미 부여된 특성과 예정된 자손은 다시 추첨하지 않는다. 이미 진행 중이거나 끝난 경매는 출품 시 저장한 평가액·수요·입찰 계획을 유지한다. 새 확률은 이후 생성 및 새 번식에 적용한다. 보유 특성과 기존 경매 가치·희귀도는 이번 등장률 상향으로 변하지 않는다.

이전 버전의 개체에는 종과 개체 ID를 씨앗으로 사용해 한 번만 특성을 부여한다. 원본의 크기·성별·사육 기록을 유지하며, 같은 원본을 다시 불러와도 결과는 같다. 기존 번식통도 부모 기록과 번식통 ID를 이용해 안정적으로 변환한다. 사망·표본 제작 이후에도 특성과 그림을 보존한다. 저장 형식 5에 선택 필드를 추가했으며, 과거 필드가 없는 기록은 유효하고 잘못된 종·중복 분류·알 수 없는 특성은 거부한다.

## 자료 판단

정확한 발생률을 산출할 수 있는 전체 표본 수와 특성별 집계는 확인하지 못했다. 특히 단일 사육 기록의 ‘처음 발견했다’는 경험이나 출처 없는 확률 언급은 자연 발생률의 분모로 사용하지 않았다.

- [COLORS의 왕사 상품·혈통 설명](https://e-colors.jp/pages/714): 자연에서 극히 드물게 보이는 컬러아이를 고정한 계통과 화이트·레드·핑크색 설명. 컬러아이를 턱 형태보다 훨씬 드물게 설정하는 질적 근거로 사용했다.

- [ドルクスダンケ의 장수 화이트아이](https://www.e-mushi.com/f/4159-4163.html): 부모·자손의 컬러아이 사육 사례.

홍다리의 짙은 붉은색, 다우리아·두점박이의 게임 특성에 대해서는 명명된 희귀 변이 혈통의 발생 통계를 확인하지 못했다. 특히 ‘쌍첨턱·대점형·황금날개’는 해당 종의 기존 픽셀 외형을 강조하는 게임 특성으로 한정했다.

검증: 31종 775만 회 자연 발현 추첨에서 특성별 확률 분포, 양 성별 동등성, 새 돌연변이의 절대 확률, 30%·75% 유전, 희귀도별 성충·표본·유충 평가, 고정된 입찰자 예산, 과거 저장 및 경매 평가 보존.

## 추가 종

톱의 적갈색형은 [むしなび의 직접 사육·체색 관찰](https://mushinavi.com/navi-insect/data-kuwa_noko.htm)을, 애의 화이트아이는 [사육자가 직접 작성한 누대 기록 모음](https://blogtag.ameba.jp/news/ホワイトアイコクワガタ)을 참고했다. 정확한 발생률이나 한국산 혈통에 대한 유전 실험을 확인한 것은 아니며 새 확률도 게임 설정이다. 대곡치·세장치·금모형·쌍첨치는 [한국산 표본과 형태 진단](./species-art-ko.md)에 착안한 게임 변이로 표시한다. 한쪽 부모 30%·같은 특성 암수 75% 유전과 희귀도 가격식이 동일하게 적용된다.



## 해외종

해외 22종에는 종마다 게임용 체색 변이(약 5.373%)와 화이트아이(약 0.627%)가 있으며 합계 6%다. 확률은 실제 발생률 통계가 아니다. 한쪽 부모 30%·같은 특성 양쪽 부모 75%와 기존 경매 희귀도 계산을 적용한다. 종별 자료는 [해외 원정](./overseas-ko.md)을 참고한다.
