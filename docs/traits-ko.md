# 희귀 특성과 유전

모든 종의 수컷과 암컷에게 같은 확률로 특성이 부여된다. 턱 특성은 암컷에서 큰턱으로 표현하지 않고 ‘혈통’으로 표시한다. 특성은 크기 잠재력이나 투곤 능력을 올리지 않으며, 크기·성별과 독립적으로 결정한다.

| 종 | 특성 |
| --- | --- |
| 왕사슴벌레 | 곡치, 화이트아이, 레드아이, 핑크아이 |
| 넓적사슴벌레 | 장치, 단치, 무내치 |
| 장수풍뎅이 | 레드기어(레드바디), 화이트아이, 레드아이 |
| 홍다리사슴벌레 | 진홍다리, 적흉 |
| 다우리아사슴벌레 | 호박빛, 쌍첨턱 |
| 두점박이사슴벌레 | 대점형, 황금날개 |

왕사의 극태는 사용자의 선호에 따라 제외했다. 곡치는 턱의 두께를 늘리지 않고 곡률을 표현한다. 홍다리·다우리아·두점박이의 특성 이름은 외형에서 착안한 **게임 변이**다. 실제로 고정되었거나 희귀하게 유전되는 사육 혈통이라는 주장은 하지 않는다. 실제 곤충의 형태는 유전뿐 아니라 크기·성장 환경 등에도 영향을 받는다.

게임 확률은 자연 발현 3%, 한쪽 부모 보유 15%, 같은 특성의 암수 75%다. 자손 한 마리마다 독립적으로 적용한다. 이 수치는 실제 생물학적 유전 확률이 아니다. 자연 발현 시 종별 가중치로 한 특성을 선택하므로 개별 특성의 자연 출현율은 3%보다 낮다. 다른 턱 형태나 다른 눈 색은 동시에 보유할 수 없다. 다른 분류의 특성은 최대 두 개까지 보유할 수 있다.

번식 시 각 알의 성별·크기 잠재력을 먼저 결정하고 특성을 확정해 저장한다. 부모의 특성을 분류별로 추첨하며, 부모가 모두 보유하지 않은 분류에서만 3%로 새로운 특성을 추첨한다. 실패한 부모 특성을 자연 발현으로 다시 추첨하지 않으므로 화면의 15%·75%는 정확하다. 같은 분류의 다른 특성을 가진 부모는 각 특성 15%, 기본형 70%다. 우화·새로고침·시간 경과로 다시 추첨하지 않는다.

이전 버전의 개체에는 종과 개체 ID를 씨앗으로 사용해 한 번만 특성을 부여한다. 원본의 크기·성별·사육 기록을 유지하며, 같은 원본을 다시 불러와도 결과는 같다. 기존 번식통도 부모 기록과 번식통 ID를 이용해 안정적으로 변환한다. 사망·표본 제작 이후에도 특성과 그림을 보존한다. 저장 형식 5에 선택 필드를 추가했으며, 과거 필드가 없는 기록은 유효하고 잘못된 종·중복 분류·알 수 없는 특성은 거부한다.
