# 현실 환경과 번식 크기 계산

2026-10-04 수정 기준.

## 시각과 날씨

- 현실의 숲은 현재 한국 날짜와 시각을 초 단위로 표시한다. 사육 일수는 별도 유지하며 한국 시각 자정마다 성장·돌봄·지원금을 하루씩 처리한다.
- 이전 24시간 타이머 저장은 온전히 지난 24시간을 먼저 반영한 뒤 현재 날짜 기준으로 전환한다. 전환 당일의 부분 시간을 중복 지급하지 않는다.
- 상상의 숲은 버튼 진행을 유지하며 두 세계의 데이터는 독립적이다.
- 서울 기본, 13개 한국 지역을 선택할 수 있다. Open-Meteo의 현재 날씨 모델 값을 10분마다 요청하며 기온·날씨 코드·일출·일몰을 사용한다. 실제 관측소 실측값을 보장하는 서비스는 아니다.
- 아침·낮·저녁·밤의 창밖과 조명, 구름·비·눈·안개를 표현한다. 비·눈은 창문 안에서만 애니메이션하며 방 배경은 시간대·날씨별로 캐시한다.
- 연결 실패 시 실패 상태를 표시하고 최근 정보가 있으면 이전 정보라고 표시한다. 3시간 넘은 정보는 현재 날씨로 쓰지 않는다. 날씨는 개체의 건강이나 성장 속도를 바꾸지 않는다.

API 기준: [Open-Meteo 공식 문서](https://open-meteo.com/en/docs).

## 자료에서 확인한 부분

[월야노 기노코엔의 직접 사육 기록](https://kuwakabu.tsukiyono.co.jp/2017/11/24/国産オオクワガタの飼育%E3%80%80小さな親から大きく羽/)에는 수컷 71mm·암컷 41mm 부모에서 83.8mm 수컷이 나온 사례가 있다. 이 사례는 Element 1100/1400 **균사병**과 온도 관리로 사육한 기록이며, 단순 톱밥만 사용한 사례로 인용하지 않는다. 자손 크기는 부모 길이에만 고정되지 않고 먹이와 사육 환경에 영향을 받는다는 구현 방향의 참고 자료다.

실제 사육의 결과를 보장하는 보편적인 계산식이나 ‘60mm 수컷 × 30mm 암컷이면 반드시 70mm’라는 법칙은 확인하지 못했다. 아래의 수치는 플레이어의 요청을 반영한 **게임 조정값**이다.

## 게임에 적용한 조정

- 부모의 실제 몸길이를 암수 체형 차이에 맞춰 환산해 자손의 기준 크기로 사용한다. 부모 크기·종별 먹이 적합성·관리 상태에 따라 성장 결과가 달라진다.
- 먹이의 신선도와 먹이 종류의 영양을 따로 누적한다. 기본 톱밥의 영양 수치가 낮다는 이유만으로 돌봄 실패로 계산하지 않는다.
- **넓적사슴벌레**의 60mm 이상 수컷과 30mm 이상 암컷을 교배하고 톱밥을 잘 교체하면 수컷 자손은 주로 70mm대, 유전 변동이 유리할 때 드물게 80mm대가 된다. 수컷 상한은 82mm다.
- **왕사슴벌레**에는 위 톱밥 규칙을 적용하지 않는다. 대형육성매트를 포함해 매트만 먹인 수컷은 게임 내에서 70mm 미만으로 제한한다. 균사를 실제로 먹인 기간을 누적하고 관리 상태·부모 크기·유전 변동과 함께 계산한다. 마지막에 균사병으로 바꾸는 것만으로 전체 사육 기간의 균사 효과를 얻을 수 없다. 왕사슴벌레 번식 상한은 수컷 86mm·암컷 49mm다.
- 야생 왕사슴벌레 수컷의 채집 상한 69mm는 유지한다. 기존 성충의 크기를 소급해 바꾸지 않으며 진행 중인 번식통부터 새 우화 계산을 적용한다.
- 관리가 부족하면 성장 결과가 감소한다. 새 계산은 빠른 성장과 실제 성장 기간에 동일하게 적용한다.

검증: 자정·월말·저장 이전, 날씨 응답 실패·노후화, 다수 번식의 기본매트/고급매트/방치 비교, 기존 채집·투곤·표본 제작 회귀 검사.
