# 9종과 채집지, 픽셀 원화

2026-10-04에 톱사슴벌레(`saw`), 애사슴벌레(`little`), 사슴벌레(`stag`)를 추가했다. 사슴벌레는 한국산 `Lucanus maculifemoratus dybowskyi`로, 외국의 다른 Lucanus 종을 대신 넣지 않았다. 야생·번식 길이 범위, 희귀도, 출현 비중, 성장 기간, 전투·가격 수치는 게임 설정이다.

## 사진에서 확인하고 새로 그린 모습

한국산 분류 논문의 Figure 12 암수 표본 도판을 직접 열어 확인했다. 48×72의 정수 픽셀 원화와 88×48의 옆모습을 코드로 다시 그렸다. 원본 사진을 축소하거나 윤곽을 자동 추적한 결과가 아니며 사진 파일은 앱에 포함하지 않는다.

| 종 | 위에서 본 원화에 반영한 차이 |
| --- | --- |
| 왕사슴벌레 | 검은 몸, 넓은 머리, 큰턱의 큰 내치, 암컷의 짧은 턱과 딱지날개 줄 |
| 넓적사슴벌레 | 몸보다 넓은 수컷 머리, 긴 큰턱의 안쪽 돌기, 상대적으로 납작한 옆모습 |
| 장수풍뎅이 | 넓고 둥근 딱지날개, 수컷의 갈라진 머리뿔과 앞가슴뿔, 뿔 없는 암컷의 거친 표면 |
| 홍다리사슴벌레 | 길고 가느다란 수컷 턱, 어두운 몸, 암수의 붉은 다리 |
| 다우리아사슴벌레 | 갈색 수컷, 각진 머리와 들린 큰턱, 더 어두운 암컷 |
| 두점박이사슴벌레 | 황갈색 몸, 앞가슴의 짝 무늬, 긴 수컷 턱과 짧은 암컷 턱 |
| 톱사슴벌레 | 적갈색 체색, 활처럼 휜 수컷 톱니턱, 암컷의 둥근 달걀형 몸 |
| 애사슴벌레 | 좁고 길쭉한 몸, 가는 수컷 턱의 내치, 작은 암컷 머리 |
| 사슴벌레 | 수컷 머리 뒤의 넓은 돌출부, 여러 톱니, 암수의 짧은 털 질감 |

옆모습은 등면 그림을 회전한 이미지가 아니라, 별도 윤곽으로 머리·앞가슴·딱지날개·큰턱/뿔·관절 다리를 그렸다. 암컷의 턱 특성은 혈통으로 보유하며 수컷 턱이 붙지 않는다. 눈·체색·다리·무늬 특성은 양 성별에서 표현한다. 장치·단치·무내치와 왕사 곡치도 유지하며 극태는 없다.

사육장 카드, 번식 부모, 도감, 라인, 경매, 완성 표본은 동일한 종·성별·특성 원화를 사용한다. 완성 표본은 작업 중 다리 선을 합성한 이미지 대신 원래 픽셀 원화를 표시한다. 이미 저장된 개체, 특성, 라인, 경매의 상태나 평가액을 다시 생성하지 않는다.

## 채집지 구성

기존 6개 장소 ID는 저장 호환을 위해 유지했다. 수색·이동·접근·포획 조작은 동일하다. 평지·수액 / 고목·잡목 / 서늘한 산지 / 남쪽 섬으로 골라 볼 수 있고 장소 카드에는 시간·탐험 비용, 안내에는 실제 출현 가능한 종 전체를 표시한다.

| 채집지 | 출현 가능한 종 |
| --- | --- |
| 참나무 숲 | 넓적 · 톱 · 장수 · 애 |
| 깊은 숲 | 왕 · 애 · 넓적 |
| 마을 뒷산 | 장수 · 톱 · 애 |
| 계곡 고목지대 | 홍다리 · 애 · 왕 · 사슴 |
| 고산 활엽수림 | 사슴 · 홍다리 · 애 · 다우리아 |
| 남쪽 섬 상록수림 | 넓적 · 톱 · 장수 · 두점박이 |
| 버드나무 둔치 | 톱 · 넓적 · 장수 |
| 잡목 숲 | 애 · 톱 · 넓적 |
| 서늘한 산 능선 | 사슴 · 홍다리 · 애 · 다우리아 |
| 수액 나무길 | 톱 · 넓적 · 장수 |
| 참나무 공동 | 왕 · 애 |
| 과수원 가장자리 | 장수 · 톱 · 애 |

두점박이는 섬에서, 다우리아는 산지에서만 만난다. 미끼 덫과 유인등도 이 출현 목록을 벗어나지 않는다. 목록·비중은 종의 서식 자료에 착안한 게임용 분배이며 실제 분포 지도나 야생 채집 확률은 아니다. 조사 흔적의 종류와 풍부함에 따라 목록 안에서 가중치가 달라진다.

## 확인한 일차 자료

- [Kim & Kim (2010), Review of family Lucanidae (Insecta: Coleoptera) in Korea with the description of one new species](https://www.zin.ru/animalia/coleoptera/pdf/kim_kim_2010_review_lucanidae_korea.pdf): pp. 74–76, Figure 12 f–j 및 n–q의 8종 암수 표본 사진. 학명, 형태 진단, 한국산 기록. PDF를 내려받아 도판을 직접 확인했다.
- [벨기에 왕립자연과학연구소의 장수풍뎅이 표본](https://virtualcollections.naturalsciences.be/virtual-collections/entomology/coleoptera/dynastidae/dynastinae/allomyrina-dichotoma-dichotoma-linnaeus-1771-1): 등면·측면과 암수의 뿔·몸 형태를 비교했다. 페이지에 아종별 표본이 함께 있어 아종별 분포·치수 자료로 사용하지 않았다.
- [Ben Harink의 톱사슴벌레 사진·사육 기록](https://www.beetlebreeding.ch/prosopocoilus-inclinatus/): 수컷 표본과 발효목/매트 사육 설명.
- [Ben Harink의 애사슴벌레 사진·사육 기록](https://www.beetlebreeding.ch/dorcus-rectus/): 암수의 형태와 부후목·발효매트 설명.
- [Ben Harink의 사슴벌레 표본·사육 설명](https://www.beetlebreeding.ch/lucanus-maculifemoratus-dybowskyi/): 수컷 표본. 사육 설명은 근연 아종에서 유추한 내용이므로 검증된 한국산 발육 통계로 사용하지 않았다.
- [국립수목원의 사슴벌레 암수 동정 답변](https://kna.forest.go.kr/kfsweb/cop/bbs/selectBoardArticle.do?bbsId=BBSMSTR_1109&nttId=3186005): 귀처럼 돌출된 수컷의 머리 뒤 형태.

수치는 위 자료의 표본 몇 마리를 전체 종의 최대 기록이나 확률로 환산한 값이 아니다. 성충의 큰턱 길이는 크기와 성장 환경에도 영향을 받는다. 새로운 명명 특성 중 대곡치·세장치·금모형·쌍첨치는 사진에서 관찰한 외형을 강조한 게임 변이다.
