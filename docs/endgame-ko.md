# 후반 원정과 연구설비

해외 원정은 16곳에서 28곳으로, 해외 곤충은 22종에서 28종으로 늘었다. 상단 탭은 8개를 유지한다. 자격 없이도 여행비만 있으면 언제든 원정에 출발하며 이동·탐사·귀국 대기가 없다. 생체 반입에는 기존 해외 생체 취급 자격을 적용한다. 모든 비용·출현 가중치·특성·설비 효과는 게임 설정이다.

| 라오스 | 2,600 | 그란디스·기라파 |

세계지도에 실제 위도·경도에 따른 새 표시를 추가하고 휠 확대·축소, 드래그, 접는 원정지 목록을 유지한다. 기존 원정의 종 구성과 이미 받은 원정지·해외 도감 보상은 바꾸지 않는다. 미획득 종은 기존 도감에서 완전히 숨긴다.

## 고액 원정

| 방식 | 기본 여행비 외 추가 비용 | 탐사 수 | 효과 |
| --- | ---: | ---: | --- |
| 일반 | 0 | 3 | 기존 크기 분포·특성 6% |
| 대형 개체 | 12,000 | 4 | 야생 크기 분포를 대형 쪽으로 이동 |
| 특성 집중 | 35,000 | 5 | 자연 특성 등장률 3배, 해외종 합계 18% |
| 최상급 | 90,000 | 6 | 대형 분포·특성 18%, 모든 탐사를 마치면 특성 개체 최소 1마리 |

예: 볼리비아 최상급 원정은 28,000 + 90,000 = 118,000이파리다. 선택 화면과 출발 확인 창에서 총액을 보여준다. 원정 방식과 지정 종, 이미 발견한 개체를 저장하여 새로고침으로 바뀌지 않는다. 최상급에서 5회까지 특성이 하나도 나오지 않았으면 마지막 탐사에 기존 종별 상대 확률로 특성 한 개를 부여한다. 중간 귀국하면 최소 1마리 보장을 받지 않는다. 추가 비용은 완료 도감 보상에 더하지 않는다.

## 영구 연구설비

상점의 사육·원정 설비에서 각각 한 번 구매하며 구매한 숲에 영구 적용한다.

| 설비 | 가격 | 효과 |
| --- | ---: | --- |
| 해외 채집 본부 | 50,000 | 모든 원정에서 현지 출현 종 한 종을 지정, 해당 원정의 모든 탐사에 적용 |
| 정밀 육성 연구실 | 80,000 | 모든 종 새 번식 자손의 성장 잠재력 +0.035 |
| 항온항습 연구동 | 120,000 | 모든 종 유충 먹이 유지 기간 +50%, 성충 바닥재 소모 −25% |
| 유전 연구소 | 200,000 | 새 번식의 자연 발현 확률 2배, 부모 유전 30%·75% 유지 |

종 지정은 현지에 없는 종을 선택할 수 없다. 일반·고급 원정 모두 적용하며 성별과 특성은 계속 추첨한다. 연구실도 종별 크기 범위와 영양·관리·부모 조건을 따른다. 유전 연구소는 부모가 보유하지 않은 특성 분류에만 발현 상향을 적용하며 기존 개체·번식통의 정해진 자손을 재추첨하지 않는다. 번식 화면에서 적용된 자연 발현 합계와 30%·75% 유전 확률을 함께 보여준다. 항온항습 연구동은 기존 종별 설비와 곱연산으로 누적되며 젤리 교체 주기는 유지한다.

## 새 곤충과 자료

새 6종은 그란티장수풍뎅이(*Dynastes grantii*), 티티우스장수풍뎅이(*D. tityus*), 사탄장수풍뎅이(*D. satanas*), 엘라푸스가위사슴벌레(*Cyclommatus elaphus*), 아돌피나금색사슴벌레(*Lamprima adolphinae*), 멜리사슴벌레(*Homoderus mellyi*)다. 국내와 같은 외곽선·몸통 명암·분절된 다리 스타일로 위·옆모습을 적용한다. 장수의 위아래 뿔, 그란티·티티우스의 점무늬, 사탄의 검은 체색과 뿔 아래 털, 엘라푸스의 긴 큰턱, 아돌피나의 금속빛, 멜리의 앞가슴 돌출부와 무늬를 구분한다.

| 종 | 현실 성장 기간 게임 범위 |
| --- | --- |
| 그란티 | 450~810일 |
| 티티우스 | 360~720일 |
| 사탄 | 570~960일 |
| 엘라푸스 | 240~450일 |
| 아돌피나 | 180~360일 |
| 멜리 | 240~450일 |

기간·각 령 배분·크기·사육 배율에는 추정과 게임 조정이 포함된다. 상상 모드는 기존 15일, 현실 성장 모드는 종별 무작위 일정이다. 새 장수류는 장수 전용 먹이·젤리 주기를 적용하고 새 사슴벌레는 발효톱밥으로 산란·사육한다. 기존 두 광사슴벌레의 카와라 조건을 유지한다. 새 종에도 해외 특성 2종과 기존 유전·경매·라인·표본·교환 기능을 적용한다.

- [University of Nebraska: Dynastes grantii](https://unsm-ento.unl.edu/Guide/Scarabaeoidea/Scarabaeidae/Dynastinae/Dynastinae-Tribes/Dynastini/Dynastes/D-granti/D_granti.html): 미국 남서부 분포와 회백색 외형.
- [University of Nebraska: Dynastes tityus](https://unsm-ento.unl.edu/Guide/Scarabaeoidea/Scarabaeidae/Dynastinae/Dynastinae-Tribes/Dynastini/Dynastes/D-tityus/Dtityus.html): 미국 동부 분포와 짧은 뿔·올리브색 몸.
- [University of Nebraska: Dynastes satanus](https://unsm-ento.unl.edu/Guide/Scarabaeoidea/Scarabaeidae/Dynastinae/Dynastinae-Tribes/Dynastini/Dynastes/D-satanus/Dsatanus.html): 볼리비아 융가스 분포와 검은 몸·뿔 아래 털. 자료의 옛 표기는 학명 표준 *satanas*로 저장한다.
- [Museums Victoria: Cyclommatus elaphus](https://collections.museumsvictoria.com.au/specimens/2631358): 수마트라 표본·형태.
- [Museums Victoria: Lamprima adolphinae](https://collections.museumsvictoria.com.au/specimens/2630834): 파푸아뉴기니 와우 표본과 좌표.
- [Lund University Biological Museum](https://ento.biomus.lu.se/search.php?family=Lucanidae&taxa=Lucaninae): 멜리의 카메룬 표본 기록.
- [Lund University: Nepal Lucanidae](https://ento.biomus.lu.se/search.php?country=Nepal&taxa=Lucanidae): 안테우스의 네팔 표본.
- [Taxonomic revision of the Dorcus curvidens and D. grandis species groups](https://www.researchgate.net/publication/398671439_Taxonomic_revision_of_the_Dorcus_curvidens_and_D_grandis_species_groups_Coleoptera_Lucanidae_Lucaninae_in_the_Indochinese_Peninsula): 그란디스의 라오스 모식산지.

검증: 전 종·원정지 호환, 3/4/5/6회 즉시 탐사, 총액 차감과 부족 시 무변경, 대형·특성 분포, 최상급 마지막 특성 보장, 종 지정·자격·공간 제한, 연구설비의 실제 성장·소모·발현 효과, 기존 저장·자손·경매 보존, 숲별 저장, 구매·확인·탐사·귀국 화면.
