# 모두의 사육 시리즈 참고와 이번 이식

확인한 자료는 2편 《みんなの飼育シリーズ(2) ぼくのクワガタ》의 공개 공략과 3편 《みんなの飼育シリーズ ぼくのカブト・クワガタ》의 공식 출시 목록·상품 설명이다. 직접 플레이 검증은 하지 않았다. 아래에서는 자료로 확인한 원작 구성과 작은 숲에 새로 설계한 규칙을 구분한다.

## 원작의 콘텐츠 구성

| 구성 | 확인한 내용 | 플레이에서 하는 역할 |
|---|---|---|
| 채집과 도감 | 2편은 40종과 채집하기 어려운 종을 포함한다. 3편 상품 설명은 마을과 숲 탐색, 채집, 도감 완성을 제시한다. | 다른 장소와 희귀종을 계속 찾을 이유를 준다. |
| 사육과 능력 | 2편 공략에는 종별 발힘과 레벨·공격·방어·속도 육성이 기록되어 있다. | 잡은 개체를 계속 관리할 이유를 준다. |
| 훈련 | 레이스·줄다리기·씨름과 훈련용 장비가 존재한다. | 사육한 개체를 경기 준비에 연결한다. |
| 상점 | 먹이·사육용품·덫·훈련 장비를 판매하며 일부 상품은 날짜가 지나야 들어온다. | 새 도구를 얻는 시점을 나눠 진행감을 만든다. |
| 대회와 라이벌 | 날짜별 대회 보상과 라이벌 경기가 있다. | 육성한 결과를 확인할 목표를 준다. |
| 주민 요청 | 특정 종을 보고 싶어 하는 주민과 곤충을 감정하는 박사가 등장한다. | 도감 수집을 구체적인 요청으로 바꾼다. |

자료에서 읽히는 흐름은 **탐색·채집 → 사육·훈련 → 대회·요청 → 보상·새 도구 → 더 어려운 채집과 육성**이다. 이는 자료를 종합한 해석이며, 각 편이 똑같은 규칙을 사용한다는 뜻은 아니다.

## 작은 숲에 넣은 세 가지

| 원작에서 가져온 개념 | 작은 숲의 구현 | 조정한 이유 |
|---|---|---|
| 여러 미끼 덫과 유인등 | 수액 덫·발효 과일 덫·유인등을 채집지에 최대 2개 설치한다. 게임의 다음 날 확인하면 빈 덫 또는 포획 전 만남이 생긴다. 발견한 곤충은 직접 접근하고 포획한다. | 채집에 장소·미끼 선택과 기다리는 단계를 추가한다. 설치 수, 하루 대기, 확률은 새 규칙이다. |
| 줄다리기·장애물 훈련 | 장비를 한 번 구매하면 계속 사용한다. 개체당 하루 한 번, 20 잎사귀와 포만감 8을 소비한다. 발힘·지구력이 각각 최대 12까지 오른다. | 돌봄을 투곤 준비와 연결한다. 발힘 보너스는 최대 6%, 추가 지구력은 최대 18로 제한해 크기 차이가 여전히 크게 작용한다. |
| 특정 종을 보여 달라는 주민 요청과 도감 | 도감에 연구소 의뢰 6개를 순서대로 둔다. 일반종 등록, 왕사 등록, 번식통 우화, 희귀종 등록을 달성하면 잎사귀·경험치를 한 번 받는다. | 수집·번식의 다음 목표를 명확하게 제시한다. 연구소 의뢰 형식과 보상 수치는 새로 설계했다. |

원작의 날짜별 상품 확장은 상점 개방 조건에도 반영했다. 이 게임에서는 날짜에 레벨과 실적을 함께 요구한다.

| 상점 구역 | 필요한 조건 — 모두 충족 |
|---|---|
| 기본 사육용품 | 처음부터 개방 |
| 영양 젤리 | Lv.2 · 5일째 · 채집 5마리 |
| 발효매트·산란 | Lv.3 · 9일째 · 채집 10마리 · 번식 1회 |
| 균사 사육 | Lv.4 · 15일째 · 채집 16마리 · 번식통 우화 1회 |
| 대형 개체 육성 | Lv.5 · 24일째 · 채집 24마리 · 번식통 우화 3회 |

이번 투곤은 크기·종별 발힘·건강·포만감·피로를 계산하는 자동 경기다. 훈련은 작은 보정만 준다. 희귀종의 출현율과 야생·번식 크기 범위도 작은 숲의 게임 설정이다. 원작 수치나 실제 곤충의 최대 기록을 그대로 옮긴 값은 아니다.
