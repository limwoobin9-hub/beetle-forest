# 라인 관리

두 세계의 라인은 별도로 저장되며 로그인한 계정에서는 세계 기록과 함께 동기화된다.

1. 라인 탭에서 새 라인 만들기를 누르거나, 번식 화면에서 종충을 선택한 뒤 이 종충 쌍으로 새 라인을 누른다.
2. 같은 종의 보유 수컷·암컷을 선택하고 1~24자 이름을 입력한다. 여섯 종 모두 가능하다.
3. 종충은 P로 지정된다. 같은 라인 부모끼리 교배하면 높은 부모 누대에서 하나 올라가며, P × P는 F1, F1 × F1은 F2가 된다. 번식통에서 정해진 라인은 우화할 때 양쪽 성별 모두에게 이어진다.
4. 라인 관리 화면에서는 종충, 누대별 개체, 사육 중 암수, 누적 후손, 성장 중 번식통과 교배·우화 기록을 확인한다. 개체 카드와 사육실·번식창·표본 라벨에도 라인명과 누대가 표시된다.

한쪽 부모만 라인이 있으면 해당 라인을 이어받고 외부 개체 교배로 기록한다. 서로 다른 라인이면 후손을 기록할 라인을 직접 선택해야 번식할 수 있으며, 교배 기록에는 두 부모의 출신 라인이 남는다. 누대는 선택한 라인의 부모 기준으로 올라간다. 이는 게임의 기록 규칙이며 실제 유전적 순수도를 판정하지 않는다.

라인을 나중에 지정하면 현재 보유·보관 중인 개체의 부모 ID로 확인 가능한 미지정 후손과 번식통도 연결한다. 이미 이름 붙은 라인 후손의 지정은 유지한다. 다른 라인의 개체를 새 종충으로 지정할 때는 이전 라인 출신 기록을 남기고 새 라인의 P부터 시작한다. 과거에 이미 시작한 번식통은 산란 때 지정된 라인을 유지한다.

이름 변경은 같은 라인 ID를 유지해 기존 후손의 표시도 함께 바꾼다. 라인 보관은 관리 목록만 숨기며 후손·교배 기록과 이후 유전을 유지한다. 보관한 라인 목록에서 다시 복귀할 수 있다. 방생하거나 표본이 된 개체도 역사 기록에는 남는다.

기존 v5 저장은 라인이 없더라도 그대로 읽을 수 있다. 라인 기록에는 부모·후손의 최소 스냅샷을 저장하여 부모가 방생되거나 별도 라인으로 이동한 뒤에도 당시의 교배 정보를 보존한다.
