# 사육실 확장

상점의 **사육·원정 설비** 구역에서 순서대로 구매한다. 레벨 제한은 없고 이파리만 필요하다. 각 숲의 영구 설비로 따로 저장된다.

| 단계 | 수용량 | 해당 단계 가격 |
| --- | ---: | ---: |
| 기본 | 48마리 | — |
| 1단계 | 60마리 | 2,000이파리 |
| 2단계 | 72마리 | 5,000이파리 |
| 3단계 | 96마리 | 12,000이파리 |
| 4단계 | 120마리 | 25,000이파리 |

현재 성충과 번식통 후손(통당 3마리), 경매에 맡긴 생체의 복귀 공간을 함께 계산한다. 확장 후 채집, 덫, 번식, 사건 손님, 해외 생체 귀국, 경매 복귀, 세계 간 교환 및 일괄 교체에서 늘어난 공간을 사용한다. 번식통 수는 기존 3개를 유지한다.

앞 단계 미구매, 중복 구매, 이파리 부족은 재고·금액을 변경하지 않는다. 기존 저장 데이터는 기본 48마리로 읽고, 구매한 확장 설비의 순서와 수량을 검증하여 확장 수용량으로 저장·복원한다.
