# 전체 개체 일괄 교체

사육실에서 젤리와 바닥재를 각각 일괄 교체할 수 있다. 선택한 용품을 보유 성충마다 1개씩 사용한다. 종·성별·즐겨찾기 필터로 숨겨진 개체와 아직 교체 시기가 오지 않은 개체도 포함한다. 유충과 번식통은 포함하지 않으며 유충 전용 톱밥은 성충용 바닥재 목록에 표시하지 않는다.

선택한 용품의 필요 수량·보유 수량·부족 수량을 버튼 위에 표시한다. 재고가 부족하면 부족 메시지를 보여주고 전체 작업을 중단한다. 다른 종류의 용품으로 임의 대체하거나 일부 개체만 교체하지 않는다. 투곤이 진행 중이면 일괄 교체를 진행하지 않는다.

설정의 **용품 부족 시 자동 구매**는 기본적으로 꺼져 있고 각 숲에 따로 저장된다. 켜면 개별 및 일괄 젤리·바닥재 교체에 적용된다. 선택한 제품의 부족분을 기존 상점의 묶음 수량과 가격으로 구매하며, 남은 재고는 보관한다. 예를 들어 바나나 젤리가 1개 있고 성충이 8마리이면 6개짜리 2묶음을 80이파리에 구매하고, 교체 후 5개가 남는다. 이파리가 전체 구매 금액보다 부족하거나 해당 상점이 잠겨 있으면 구매와 교체를 모두 진행하지 않는다.

기존 저장 데이터는 자동 구매를 끈 상태로 유지한다. 일괄 교체를 반복해도 개체·돌봄 종류별 하루 경험치 보상은 한 번만 지급한다.
