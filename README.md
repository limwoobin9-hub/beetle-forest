# 작은 숲 · 곤충 사육

사슴벌레·장수풍뎅이 6종을 채집하고 사육·번식·훈련하는 브라우저 게임.

- 채집지 6곳, 희귀종, 미끼 덫과 채집 결과에서 방생
- 알 → 1령 → 2령 → 3령 → 번데기 → 성충
- 크기·컨디션·피로가 반영되는 자동 투곤
- 레벨과 채집·번식 실적에 따라 열리는 용품점
- 카드에서 젤리·매트 교체와 즐겨찾기
- 종·성별·즐겨찾기 필터와 크기·지구력·발힘·건강·허기의 양방향 정렬
- 설정에서 현실 시간 연동과 실제 성장 기간 선택

## 실행

```sh
npm ci
npm run dev
npm test
```

## Vercel

이 저장소를 가져오고 프로젝트 이름을 `beetle-forest`로 지정한다. `vercel.json`에 따라 테스트 통과 후 `dist`를 정적 파일로 배포한다. 서버·데이터베이스·환경변수는 필요 없다.

게임은 브라우저에 자동 저장된다. 다른 주소의 사이트나 다른 브라우저와 저장 데이터를 자동 공유하지 않는다.

## 시간 설정

기본 모드는 다음 날 버튼으로 진행한다. 현실 시간 연동은 켠 시점부터 24시간마다 하루가 진행되며, 다시 접속할 때 오프라인 경과 시간도 반영한다. 실제 성장 기간은 현실 시간 연동에서 사용할 수 있다. 대표 성장 주기는 약 180~365일이며 온도·먹이에 따른 실제 생육 변동을 전부 재현하지는 않는다.

현재 성장 단계와 단계 안의 진행률은 설정을 바꿀 때 유지한다. 시간 설정을 바꾸거나 저장 파일을 다시 읽어도 같은 날의 보상을 반복해서 받지 않는다.
