# 작은 숲 · 곤충 사육

국내 9종·해외 28종의 사슴벌레·장수풍뎅이를 채집하고 사육·번식·훈련하는 브라우저 게임.

- 국내 채집지 12곳 · 지역별 출현 종, 대형 개체 탐사, 미끼 덫과 채집 결과에서 방생
- 픽셀 세계지도에서 선택하는 해외 원정지 16곳 · 여행비만으로 출발 · 실제 시간 이동과 탐사
- 해외 생체 취급·보호종 판매 자격 · 미자격 원정은 표본용 처리 후 반입
- 획득한 종만 표시하는 도감 · 지역별 도감 완성 보상
- 4체급 주간 투곤 리그 · 반복 수집가 납품 의뢰
- 7개 상점 구역, 40개 용품 · 6개 해외 전용 먹이와 8개 사육 및 원정 설비
- 알 → 1령 → 2령 → 3령 → 번데기 → 성충
- 크기·컨디션·피로가 반영되는 자동 투곤
- 레벨과 채집·번식 실적에 따라 열리는 용품점
- 카드에서 젤리·매트 교체와 즐겨찾기
- 종·성별·즐겨찾기 필터와 크기·지구력·발힘·건강·허기의 양방향 정렬
- 설정에서 실제 성장 기간, 13개 지역의 날씨 연동 선택
- 아이디·비밀번호로 가입·로그인, 이메일 인증 없이 계정별 두 세계 저장
- 한국 현재 시각과 아침·낮·저녁·밤, 창밖 비·눈·구름·안개 연동
- 부모의 실제 몸길이와 애벌레 먹이 신선도·영양을 구분해 자손 크기 계산
- 현실의 숲·상상의 숲을 선택해 독립된 사육 기록으로 진행, 현재 세계 새로고침
- 건강 20 이하가 7일 연속 지속되면 사망, 개체 보관함에 생전 기록 보존
- 매일 사육 지원금: 기본 15 + 성충당 2 + 번식통 후손당 1 + 건강한 성충당 1, 하루 최대 80 잎사귀
- 손으로 작업하는 표본 제작: 연화상 조립 → 연화 → 주핀·높이 → 다리·더듬이 정리와 보조핀 → 건조 → 보조핀 제거 → 라벨 → 별도 케이스에 배치
- 종충 쌍으로 이름 붙이는 라인, P → F1 → F2 누대·교배 이력과 전용 관리 화면
- 완성한 표본은 원래 개체의 픽셀 그림과 특성으로 케이스에 보관
- 상점 아래 곤충 경매: 성충·유충 묶음·완성 표본 출품, 시작가·기간 설정, 가상 자동 입찰·낙찰 정산
- 용품·잎사귀가 부족한 돌봄 대상에 하루 1회 기초 용품 지원

## Vercel

이 저장소를 가져오고 프로젝트 이름을 `beetle-forest`로 지정한다. `vercel.json`에 따라 Supabase와 게임을 변경된 파일 이름의 브라우저 번들로 생성하고 테스트를 통과한 뒤 `dist`를 배포한다. 인증과 기록 저장은 연결된 Supabase 프로젝트의 `beetle-auth` 함수와 `beetle_world_saves` 테이블을 사용한다. 서버 비밀 키는 Supabase 함수의 환경변수에서만 읽는다.

로그인하면 두 세계를 계정에 자동 저장하고 다른 기기에서 이어갈 수 있다. 비로그인 기록과 계정별 기기 캐시는 분리한다. 빈 계정에서는 기존 브라우저 기록을 명시적으로 가져올 수 있다. 네트워크 실패 시 미전송 기록을 기기에 유지하고 재시도하며, 다른 기기의 저장과 충돌하면 최신 계정 기록을 불러오기 전까지 서버 덮어쓰기를 중단한다.

Supabase 설정과 인증 검증: [계정 구현](docs/accounts-ko.md).

## 시간 설정

처음에는 세계를 선택한다. 상상의 숲은 다음 날 버튼으로 진행하고, 현실의 숲은 한국의 현재 날짜·시각을 표시하고 매일 한국 시각 자정에 하루가 진행되며 다시 접속할 때 오프라인 경과 시간도 반영한다. 곤충, 용품, 번식통, 보관함과 화면 설정은 세계별로 따로 저장한다. 기존 저장은 사용하던 시간 방식에 맞는 세계로 한 번 옮기고 원본을 남긴다. 세계별 주소의 `?world=real` 또는 `?world=virtual`을 유지하므로 새로고침해도 현재 세계로 돌아온다.

실제 성장 기간은 현실의 숲에서 사용할 수 있다. 대표 성장 주기는 약 180~1095일이며 온도·먹이에 따른 실제 생육 변동을 전부 재현하지는 않는다. 현실의 숲에서 접속하지 않는 동안에도 사육 상태와 사망 조건은 진행된다.

현재 성장 단계와 단계 안의 진행률은 성장 기간 설정을 바꿀 때 유지한다. 설정을 바꾸거나 저장 파일을 다시 읽어도 같은 날의 보상을 반복해서 받지 않는다. 표본 작업은 도구와 다리·더듬이를 마우스·터치로 끌어 놓으며 진행한다. 키보드로는 도구 선택 후 방향키와 Enter를 사용한다. 각 단계와 자세는 즉시 저장된다. 첫 6칸 표본 케이스와 도구는 기본 제공되며 추가 케이스는 80 잎사귀다. 완성 표본은 경매와 수집가 의뢰로 판매할 수 있다.

연화 1일과 건조 3일은 게임용 대표 대기 시간이다. 절차는 [NMSU 곤충 표본 제작 교육](https://insectcollectionlab.nmsu.edu/), [AMNH 표본 관리 안내](https://www.amnh.org/learn-teach/curriculum-collections/biodiversity-counts/arthropod-identification/maintaining-an-arthropod-collection), [Smithsonian의 딱정벌레 핀 위치 설명](https://repository.si.edu/bitstream/handle/10088/9997/USNMB_671909_unit.pdf?isAllowed=y&sequence=1)을 참고했다. 실제 제작의 모든 물리적 감각·재료·개체별 대기 시간을 재현하는 시뮬레이션은 아니다.
